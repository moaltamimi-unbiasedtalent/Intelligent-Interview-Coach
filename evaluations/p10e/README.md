# P10E evidence layout

- `authorization.json`: the owner authorization record (2026-10-19). Paid provider use is granted; **no spending ceiling, call count or approval of limits is recorded**, so every paid path refuses. Only the owner may add `limits` and `limits_approval` in a reviewed commit.
- `pricing_snapshot.json`: published provider prices for the three typed profiles at one point in time (provider metadata, not a bill).
- `execution_plan.json`: the offline plan (cases, calls, tokens and cost ranges per area; assumptions stated). Generated by `python scripts/p10e_live.py plan`; no provider call.
- `live/<run_id>/`: one directory per real provider run (`meta.json`, `calls.jsonl`, `summary.json`, optional `review_packet.json`). Created exclusively, never overwritten. **No live run exists yet.**
Offline evidence (P10C-G, P10D, P10D-R1) lives elsewhere and is not touched.

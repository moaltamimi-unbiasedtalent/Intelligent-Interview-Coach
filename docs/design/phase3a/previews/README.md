# Previews

The four prototypes were **verified live in a browser** during Phase 3A at desktop
(1440px) and mobile (390px), in light and dark themes — layout, fonts, tab
switching, the Prepare workspace + context rail, and the responsive single-column
collapse all render correctly.

Rendered PNGs are intentionally **not committed** here to keep the repository lean
(binary screenshots go stale the moment the HTML changes, and the prototypes are
the source of truth). To regenerate them yourself:

```bash
open ../index.html          # the gallery → open any concept
```

Then use each concept's in-page **Desktop / Mobile** and **Dark / Light** toggles,
or resize the browser, and capture with your OS screenshot tool. Suggested frames:
Home and Prepare at 1440px, and Prepare at 390px.

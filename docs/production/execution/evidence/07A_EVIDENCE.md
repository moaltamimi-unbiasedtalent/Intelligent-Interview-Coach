## Findings the owner or lead should decide on
- **F1 Realtime voice has no code-defined gate.** It is controlled by deployment configuration (`REALTIME_VOICE_ENABLED` plus `REALTIME_VOICE_API_KEY`, and the durable pause). With neither set it is refused and tested so; with both set a session can be minted and `/capabilities` reports it on. RELEASE_SCOPE_V1 lists live voice practice as R1.4 and "disabled by" the speech constants, but those constants do not govern it. I did not add a constant (instruction: do not change gates). Decision: add a code constant (like the speech ones) or accept deployment configuration as the gate and say so in the scope document.
- **F2 `GATE_CONSTANTS` in `reconcile_issues.py` omits five gate constants** that exist in code and are False: `AI_COST_LIMITS_ENFORCED`, `USAGE_QUOTAS_ENFORCED`, `PREPARATION_PACK_GENERATION_ENABLED`, `PREMIUM_ANALYTICS_ENABLED` and `PAID_ENTITLEMENT_POLICY_APPROVED`. The generated reconciliation document therefore does not list them. 07A asserts them False itself (table `ADDITIONAL_GATES` and the family gate tuple) and the scan fails on any future unclassified one; I did not edit the generated-document script.
- **F3 Admin Billing and Admin Speech are reachable by authorised Admins by design** (mock billing records and operations diagnostics; speech governance). They are labelled "mock / not live" and "not active" in navigation and pages and are asserted inert: nothing there can start a charge, call Stripe or make a server speech provider operational (an Admin PUT selecting STT/TTS is recorded and transcription stays 503). They are listed in the table as known routes.
- **F4 Real defects found and fixed (engineering hygiene).** Blocking calls on the event loop in: document upload and replace (pause read, rate limiter, malware-scan network call, parse/OCR/storage; a large scanned file froze every request), speech transcription (limiter plus engine run up to its timeout), the Stripe webhook limiter (shared-store network call), Admin knowledge upload and new-version (database, file store, job enqueue), Admin credential replace and remove (step-up, encryption, database), the operational-telemetry middleware (one synchronous database commit per candidate request), the AI-operation lease release (`Heartbeat.__exit__` joins a thread for up to 2 s) and the paid-run HTTP guard in `src/p10e/httpguard.py` (a blocking semaphore acquire in the async send path, the same defect `demo_live` already fixed after it deadlocked a live run). All now run in the worker pool or an executor. One optional-dependency defect: with `pytesseract`/`pdf2image` missing, `image_to_text`/`pdf_to_text` raised an OcrError of kind `ocr_failed` ("could not read this image"), which blames the document; it is now `ocr_unavailable`.

## Limits and risks
- The async scanner is a static, direct-call check plus a denylist of blocking primitives and of this codebase's known synchronous seams (`svc`, `repo`, `runtime`, limiter, pause, scan, recorders). It cannot see a blocking call hidden inside an unlisted helper; the behavioural tests cover only the routes that were offenders. A new async route that calls a blocking helper under a new name would need that name added to the denylist. `src/demo_live` and `src/p10e` guards still do small synchronous ledger writes in their async send path (bounded, serialised, paid-run-only); not changed.
- The route guard is token based (the token list is part of the table). A deferred family whose paths use none of the tokens would not be caught; extend `GATED_PATH_TOKENS` when adding a family.
- Compensation V2 and international sources are asserted by absence (no routes, no candidate-facing imports, readiness not operational). If a future package adds a route for either, the suite fails until the table lists it with its refusal.
- The anonymous persona is exercised on a production-mode app (fail-closed 401); in the test environment an unauthenticated request resolves to the development user by design (unchanged).
- The Playwright backend is mocked as the server answers with every gate off; the real API half is the Python suite. A real browser against a real backend with gates off was not run (no hosted environment).
- Scope not covered by this package: R1.2 scheduled reporting, R1.3 locales beyond the check that zh/hi/ar are unregistered and `ru` is inactive, R1.7 enterprise, R2.0, preparation-pack generation, premium analytics, usage quotas and AI cost limits (gate constants only, see F2).

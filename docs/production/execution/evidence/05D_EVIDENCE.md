## Security and privacy impact
- The webhook is unauthenticated by cookie and authenticated by secret over the raw body; constant-time comparison with no early exit; bounded body (16 KiB) read before parsing; every refusal is a bounded category (audited as `mail.webhook_rejected`, never the payload, header or secret) and the response never echoes payload, signature, secret or reason. An unknown message reference is a quiet 200 (no probing of which references exist). A storage failure is a retryable 503, never an acknowledgement.
- Stored: allow-listed state, the provider's event time and a one-way digest. NOT stored or logged: recipient, subject, link, tags, IP, user agent, the raw payload (asserted by scanning the table and audit rows for planted values). While the gate is False nothing is stored at all.
- The harness and script never print or persist a secret; Google subject appears only as an 8 hex character hash.
- No live call is possible from the test suite (a socket guard fails any non-loopback connection in the harness tests).

## Risks and limits
- The webhook authentication scheme is a design choice made without a real Brevo account: HMAC or bearer, both implemented, selected by `BREVO_WEBHOOK_AUTH`. If Brevo supports neither header shape (for example only IP allow-listing), a relay in front of the receiver or a small receiver change is needed; that is the first thing the staging run learns.
- Bearer mode has no signature timestamp; replay is bounded by event freshness (1 hour) and the idempotent digest, not by a signed window.
- The fake Redis models the interface and the script semantics, not Redis: the Lua is unproven until `TEST_REDIS_URL` or staging.
- `RATE_LIMIT_SINGLE_PROCESS_ACKNOWLEDGED` is a documentation-grade acknowledgement (a warning is suppressed, readiness reports it); it does not enforce anything.
- The harness's invitation-only check proves the rule from the policy and account lookup; the end-to-end refusal with a real Google account is a manual step in the runbook (browser required).

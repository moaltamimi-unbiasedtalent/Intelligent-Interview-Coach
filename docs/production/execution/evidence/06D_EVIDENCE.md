## Risks and limits
1. **Everything is engineering-authored.** The 49-pair dataset, the abstention questions and the new sentences were written by engineering: not independent, not native-reviewed. n=7 per pair: every pair interval is wide and a difference between pairs is not evidence.
2. The lexical hash embedder falsely answers many off-topic questions under the strict default floor (33 of 147 abstain; it scores shared function words above 0): that measures the embedder, not abstention quality. A calibrated floor for a real embedder awaits the live benchmark (02E).
3. **Finding, not fixed:** `heuristic_translation` (query understanding fallback) matches intent keywords in English only, so a non-English interview-preparation question gets no `document_type` filter while the English equivalent does. It cannot hide sources, but intent classification for six languages is unmeasured. Out of scope here (keywords need native review); recorded for 06B/06C.
4. The specific irrelevant-sources sentence is not yet on the live chat path (see item 3 of the mapping): the chat path keeps the existing localized insufficient sentence.
5. Endonyms are used for the source language name inside a sentence of another language; a localized exonym table is a reviewer decision.
6. A source chunk without a recorded `language` is never described as translated. If ingestion leaves `language` empty for most real chunks the notice will rarely appear; ingestion metadata coverage is a separate check (02A/02B).

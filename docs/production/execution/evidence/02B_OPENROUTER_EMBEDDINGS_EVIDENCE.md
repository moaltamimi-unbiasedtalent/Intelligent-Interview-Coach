## How the lead runs the later benchmark through this provider
Only after the owner has approved a budget (OD-BUDGET) and created the 05C budget configuration. Nothing here sets any of these values.
1. Budget configuration (`AI_BUDGET_CONFIG_PATH`): an `evaluation` class with an `embedding` category ceiling, a `pricing.models` entry for EVERY candidate model id (USD per token; embeddings use `prompt` only, `completion` 0; the governor refuses an unpriced model), `limits.max_input_tokens` at least the largest batch wanted (the embedder lowers its batches to this), and the owner's `approval_marker`.
2. Free checks (no tokens): run the 05C probe `python scripts/openrouter_models_probe.py` and save its stdout; then `python scripts/check_embedding_model.py --listing saved.json --model <id>` for each candidate. A dimensions value is needed only for models outside the catalogue (see below).
3. Environment for ONE run (names only; values are the owner's): `COPILOT_EMBEDDING_PROVIDER=openrouter`, `COPILOT_EMBEDDING_MODEL=<vendor/model>`, `OPENROUTER_API_KEY` (through the secret path), optional `COPILOT_EMBEDDING_DIMENSIONS` (required for a model not in the catalogue; for an OpenAI v3 model a smaller value is sent as `dimensions`), optional `COPILOT_EMBEDDING_VERSION`, `AI_BUDGET_CONFIG_PATH`, `AI_BUDGET_APPROVED_MARKER` (must equal the configured marker), `AI_BUDGET_CLASS=evaluation`, and the older 02B approval trio `ASK4MO_ALLOW_PAID_EMBEDDINGS=1`, `ASK4MO_EMBEDDING_BUDGET_MARKER=OD-BUDGET:<ref>`, `ASK4MO_EMBEDDING_MAX_CALLS=<n>`. The database must be at the 05C ledger migration. Never in CI (the governor refuses when `CI` is set).
4. Run: `python scripts/eval_multilingual_retrieval.py --embedder configured --write <path>` once per candidate model (change only `COPILOT_EMBEDDING_MODEL` and, if used, the dimensions). The script keeps its existing refusals first, then installs the governor (category `embedding`); every request is then reserved, bounded and settled. Estimate first with `--estimate-only` (no call). One model per run keeps each result tied to one identity.
5. Evidence per run: the script's result JSON plus the governor status (Admin budget status or `BudgetGovernor.status()`): ledger rows (tokens, settled cost, latency) per model. Compare quality metrics across runs; the model decision is the owner's from that table.
6. Production build after a decision: `python scripts/knowledge_embedding_rebuild.py` (dry run, report), then `--apply --target-dir <NEW empty dir> --confirm-embedder openrouter:<model>`; verify the manifest; switch `COPILOT_CHROMA_DIR` and restart API and worker (manual); roll back by switching back (the old index is never touched).

Hosted configuration variables to ADD (listed only; `deploy/docker-compose.staging.yml` and `deploy/.env.staging.example` belong to 05A and were not edited): `COPILOT_EMBEDDING_PROVIDER=openrouter`, `COPILOT_EMBEDDING_MODEL`, `COPILOT_EMBEDDING_DIMENSIONS` (when needed), `COPILOT_EMBEDDING_VERSION` (optional), `OPENROUTER_API_KEY` (already a chat variable; the embedder reuses it, `COPILOT_EMBEDDING_API_KEY` is not used by this provider), and the 05C variables `AI_BUDGET_MODE=enforce`, `AI_BUDGET_CONFIG_PATH`, `AI_BUDGET_APPROVED_MARKER`, `AI_BUDGET_CLASS`. In a hosted process the governor must be installed (`AI_BUDGET_MODE=enforce`) or every embedding call is refused with `budget_governor_not_installed`; query-time embedding of user questions is also a paid call and consumes the `production` class `embedding` category, so that category needs a ceiling in the owner's configuration before launch.

## Security and privacy impact
- The key never leaves the Bearer header; redirects are not followed; the base URL must be `https://openrouter.ai` (any other host would bypass the governor's host classification and is refused as configuration).
- Texts sent to the provider are knowledge-base chunks and user questions. Candidate documents are never embedded by this path (private candidate documents stay out of any provider call by existing design); the governed knowledge index only contains Admin-approved material. The `user` and `session_id` request fields are not sent. OpenRouter's data-collection routing preference (`provider.data_collection`) is NOT set by this package: if the owner wants `deny` or ZDR for embeddings that is a one-line request-body decision still open.
- Errors carry fixed codes only; provider text, request text and the key never appear (tested).

## Not verified (open)

## Risks and notes for the lead
- `src/knowledge_admin/contracts.py::_embedding_state` (frozen 02K) hard-codes 1536 dimensions for any resolved provider that is not `local`, so the Knowledge readiness `embedder_state.dimensions` will show 1536 for an `openrouter` model of another size. It is display-only (the manifest and compatibility check use the embedder's real identity). A one-line fix (use `embedding_status(...)["dimensions"]`) needs the contract owner.
- The governor's identical-request refusal and the embedder's per-instance cache both mean a repeated identical text is never paid twice within a process, but a restart rebuilds an empty cache; the ledger's dedupe window (300 s default) is the cross-process guard.
- The 02B `BudgetedEmbedder` call counter counts calls, not tokens; the governor ceiling is the real money bound.

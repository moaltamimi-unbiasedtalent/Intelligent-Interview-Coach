## If the text changes after your review

The owner freezes a release SHA (`python scripts/language_review_pack.py --freeze --release-sha SHA --out DIR`), which stores a snapshot of every item's digest. After later changes, `python scripts/language_review_pack.py --diff --baseline DIR/FREEZE_SNAPSHOT.json --language fr --out DIR2` lists exactly which items were added, removed, re-sourced or re-translated, so only those are re-reviewed.

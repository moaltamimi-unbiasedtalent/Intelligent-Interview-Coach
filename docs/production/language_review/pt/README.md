## If the text changes after your review

After later changes, `python scripts/language_review_pack.py --diff --baseline DIR/FREEZE_SNAPSHOT.json --language pt --out DIR2` lists exactly which items were added, removed, re-sourced or re-translated, so only those are re-reviewed.

### DF-01: UNSTATED_FACT

Fact: What a model receives, by feature. ### DF-02: UNSTATED_FACT

Fact: Embeddings. When a semantic embedding provider is configured, the retrieval query text (derived from your question) is sent to that provider; knowledge-base chunks are embedded when indexed. With no provider the product uses a local hash embedder (no network). In hosted environments the hash embedder is refused. The provider is configurable and is not named in the Privacy text.

### DF-05: UNSTATED_FACT

Fact: Retention. No fixed retention period exists for candidate content: it is kept until the user deletes it. The only time-based rule is an operator script that removes stale in-progress interview sessions after 30 days (unscheduled). Expired authentication rows are not purged automatically. Audit events are kept indefinitely with the actor link removed on deletion. A retained anonymised billing shell can outlive a deletion while a provider subscription is unresolved (no period invented).

# Pre-Submission Acceptance Gates

**Status:** CHECKLIST, generated 2026-10-19 by the integrated Candidate/Admin/Operations requalification (main `fb2d264`). A supporting document under the canonical roadmap; `capstone_phase_plan.md` stays canonical for scope and sequence. **No threshold is invented.** Where the repository defines no threshold the row says so. A passing deterministic check is never recorded as human validation, a live result or production qualification. The Turing College rubric is **not in the repository** (section 5); no assessment criterion is invented.

Status vocabulary: PASS, FAIL, PARTIAL, NOT RUN. Blocker severity: BLOCKER (cannot proceed), HIGH, MEDIUM, LOW, or `-` (none). Issue identifiers (`DI-...`) refer to `POST_SUBMISSION_DEFERRED_ISSUES_REGISTER.md`.

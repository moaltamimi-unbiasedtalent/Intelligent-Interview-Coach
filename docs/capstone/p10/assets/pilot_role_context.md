# Prepared Role Scenario — Pilot Fixture

_SYNTHETIC scenario that ties the pilot CV and JD together, so every participant tests the same
Prepare → Evidence → Practice path without exposing personal data. Moderator uses this to frame
tasks T3–T5._

## Scenario
The participant is preparing (as the fictional candidate **Alex Doe**, or simply "a candidate")
for an interview for the **Product Manager (B2B SaaS)** role at **Northwind Cloud** (see
`pilot_job_description.md`), using the synthetic CV (`pilot_cv.md`).

## What this scenario exercises
- **Prepare (T3):** begin preparing for the PM role; read Mo's guidance (or its unavailable
  state), notice Brief/Detailed/Show more and Sources, identify the next step.
- **Documents/evidence (T4):** upload the synthetic CV; review extracted evidence; accept one
  item (e.g. "reduced time-to-first-value from 9 to 5 days"), correct one item (e.g. tidy a
  garbled skill), reject one item (e.g. an over-broad claim); inspect Story Bank/provenance.
- **Practice (T5):** run Interview Practice for this role; experience question → answer →
  feedback → next; interpret the score and next action.

## Suggested focus areas (for the moderator, not to read verbatim)
- Roadmap prioritisation with evidence.
- A shipped feature that moved a measurable metric.
- Stakeholder communication / handling trade-offs.

## Notes
- This is **fictional** and contains no real personal data.
- Participants may, after the core tasks, optionally use their own **non-sensitive** career
  context — never required, and never committed to the repository.
